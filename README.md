# Digital Tennis 조직 소개

[Digital Tennis](https://github.com/digital-tennis) 조직의 첫 화면과 제품 저장소 탐색을 관리합니다.

## 이 저장소의 역할

- 공개 소개 내용은 [profile/README.md](profile/README.md)에 있습니다.
- 게임 실행과 제품별 기능은 [게임 저장소](https://github.com/digital-tennis/digital-tennis-game)에서 확인합니다.
- 구조·통신 계약·개발 과제는 [개발 문서](https://github.com/digital-tennis/digital-tennis-docs)에서 관리합니다.

## 소개 문서 수정

`profile/README.md`를 수정해 PR을 올립니다. 제품의 한 줄 설명과 링크를 최신으로 유지하고, 구현된 기능과 실기 검증 중인 기능을 구분합니다. 기술별 실행 명령·검증 로그는 해당 제품 문서에 두고 조직 소개에는 시작점만 안내합니다.

프로젝트는 NU40-DK+별도 외장 IMU를 목표로 하며 NU-54는 임시 BLE 시험용입니다. 초기 12일·3명 계획은 개발 문서에 보존합니다. 조직과 문서는 [Digital Tennis](https://github.com/digital-tennis)가 관리합니다.
